### Regex fundamentals
A regular expression describes text patterns. 

##### Use-case -> In playwright's locator assertions like `toHaveAttribute(), toHaveCSS(), toHaveId()` accepts only `string|RegExp` not glob patterns.
##### In contrast, playwright's `page.route(),page.waitForURL()` accepts a glob-style string. 

---

### Creating a Regular Expression
You can construct regular expression in one of 2 ways
```Typescript title=demo.ts
const re = /ab+c/;

const re2 = new RegExp("ab+c"); // useful when you are taking some part of string as input as parameter
```

### Decision Guide

| Use this     | When                                                                                                                      | Example                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Plain string | The expected attribute/text/CSS value is fixed and must be exactly equal                                                  | `await expect(link).toHaveAttribute('href','/help');`                  |
| Regex        | Only part is stable, or a value is dynamic; add anchors when the whole value matters                                      | `await expect(link).toHaveAttribute('href','/mailto:.*@tesco\.com/');` |
| Glob         | Matching a route or URL pattern with page.route() or page.waitForURL; it is unavailable for attribute/text/CSS assertions | `await page.waitForURL('**/api/users/*');`                             |
