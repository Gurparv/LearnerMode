Q.  When does it matter whether you call `mockApi.intercept()` before or after navigation - and why?

Q. Always mock before `page.goto()` is a safe default habit.

### Two categories of request

| Category                                                                                           | When it fires                                                                     | Must mock before `goto()`?                        |
| -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------- |
| **Load-time requests**<br>(eg initial page data: user profile, filter options, the main grid/list) | Automatically, as soon as the page starts loading  /components mount              | YES - mandatory                                   |
| **Interaction-triggered requests**<br>(eg forecast panel data, search results, form submission)    | Only after a specific user action (click, type etc) that your test performs later | No - can register any time before that action<br> |
