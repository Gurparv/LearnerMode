## Registration order vs Runtime Call Order

| Timeline A (setup Phase)                                                          | Timeline B (execution phase)                                                 |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Happens once, synchronously, when `mockApi.intercept()` is called in `beforeEach` | Happens later, repeatedly, whenever the app actually fires a network request |
| Builds a fixed, ordered list of handlers                                          | Walks that already-built list, newest-first, for each incoming request       |
