Terms:
1. mock/stub -> a canned response returned by a test code
2. intercept/route -> catch a request before it leaves the browser
3. fixture -> reusable canned data or a reusable test helper. The word has both senses
4. fulfill -> answer a caught request with a reponse
5. assertion -> a check that fails a test when it is false.

Some Mocking Code examples

1. Basic mock
```Typescript title="example.test.ts
intercept: async(pattern, data, status=200) => {
	await page.route(pattern, (route)) => 
	route.fulfill({
		status,
		contentType: 'application/json',
		body: JSON.stringify(data),
	})
	};
},	
```


2. Mock+verify query Parameters
```Typescript title="example.test.ts
interceptWithQuery: async(pattern,expectedQuery, data, status=200) => {
	await page.route(pattern, (route)) => 
	const query = new URL(route.request().url()).searchParams;
	
	Object.enteries(expectedQuery).forEach( ([key, value])) => {
		expect(query.get(key)).toBe(value);
	});
	
	return route.fulfill( {status, json: data});
	)};
},	
```

3. Error respons
```Typescript title="example.test.ts
error: async(pattern,status) => {
	await page.route(pattern, (route)) => 
	route.fulfill(
	status,
	json: {message: 'Simulated error for test', status},
	})
	);
},	
```

4. Network failure/abort
```Typescript title="example.test.ts
abort: async (pattern) => {
	await page.route(pattern, (route) => route.abort('failed'));
},
```

5. Delayed response
Holds the response for a given time before answering - useful for testing loading status
```Typescript title="example.test.ts"
slow: async(pattern, data, delayMs) => {
	awit page.route(pattern, aysnc (route)) => {
		await new Promise((resolve)) => setTimeout (resolve, delayMs));
		return route.fulfill( {status:200, json: data});
	});
},

```
Use it when: testing spinners, skeleton loaders or "this is taking a while"  messages - things that are invisible if the mock responds instantly

6. Dynamic request-based response
 The response body depends on what the request actually contained.
```Typescript title="example.test.ts"
dynamic: async(pattern, pick) => {
	await page.route(pattern, (route)) => {
		const result = pick(route.request()); // you decide the response from the request
		return route.fulfill({
			status: result.status ?? 200,
			json: result.body,
		});
	});
},
```

```Typescript test.ts
//Example usage: return a different promotion depending on the :id in the URL
await mockApi.dynamic (API_ROUTES.promotionById, (request)) => {
	const id = new URL (request.url()).pathname.split('/').pop();
	return {body: promotionById[id] ?? null, status: id in promotionsById ? 200 : 404 };
});
```

Use it when: one route pattern needs to behave differently depending on the id, method or payload - instead of registering ten near-identical `intercept` calls.

7. Sequential responses.
Returns a different body on each successive call to the same route - good for polling.
