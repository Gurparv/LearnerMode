## How Passing Arguments Works: Value vs. Reference
### Coding Concept -> Pass by Value vs Pass by Reference.

```Typescript title="demo.ts"
// How Passing Arguments Work : Value vs Reference

// Primitive type
const age = 5;

// Object
const john = {
    name: 'John',
    job : 'Developer'
}

function tryToModify(someAge: number, user:any ){
    someAge = 5 + 2;
    user.name = 'Johnny';
}

tryToModify(age,john); // primitive is always passed as 'copy of value', whereas in object case its like passing the object, so any change made will be reflected in the original as well.

// To see if Primitive value changed after function call
console.log(age); // Output: 5
// To see if Object value changed after function call
console.log(john); // Output : { name: 'Johnny', job: 'Developer' }

```

## First-Class and Higher-Order Functions

### Coding concept -> First class functions and Higher-Order functions

### First Class functions
- Javascript treats function as `first class citizens`
- This means that functions are `simply values`
- Functions are just another `type of object`

In JavaScript , `function` are type of objects.

1. Storing function as variables and object properties
```Typescript title="demo.ts"
// Function as first class
// Functions are type of objects only . And since objects are values therefore Objects are values too.

// Storing function in variables
const sum = (a:number, b:number)=>{
    return a+b
};

console.log(sum(5,5)); // 10

// Storing function in Object properties
const user = {
    name: 'John',
    age: 30,
    printSkills : function(){
        console.log('programming');
    }
}

user.printSkills(); // programming
```

2. Passing function as arguments.
```Typescript title="demo.ts"
// Function as first class
// Functions are type of objects only . And since objects are values therefore Objects are values too.

// Passing functions as arguments to other functions
const add = function(a:number, b:number):number{
    return a+b;
}

const msg ='hey';

function myFunc (m: string, someFunc:(a:number,b:number)=>number){
    console.log(m);
    console.log(someFunc(5,5));
}

myFunc(msg, add); // hey \n 10
```

3. Return function FROM function

## The call and apply methods

```Typescript title="demo.ts"
const john = {
    name: 'John',
    age: 30,
    whoAmI : function(greet:string){
        console.log(`${greet} , I am ${this.name}, aged ${this.age}`);
    }
};

john.whoAmI('Heelo'); // Heelo , I am John, aged 30


const Intro = john.whoAmI;

//Intro(); // error becoz this function cannot read Object Method 'this' keyword

// Fix using call Method
Intro.call(john,'Hi Call!'); //Hi Call! , I am John, aged 30

// Fix using apply Method
Intro.apply(john,['Hola Apply']); //Hola Apply , I am John, aged 30
```

Note -> 'Apply' method is not used anymore in modern JS.

Another Example.
```Typescript title="demo.ts"
function greet(city, country) {
  console.log(`Hi, I'm ${this.name} from ${city}, ${country}`);
}

const user = { name: "Rahul" };

// call — args individually
greet.call(user, "Mumbai", "India");
// Hi, I'm Rahul from Mumbai, India

// apply — args as array
greet.apply(user, ["Mumbai", "India"]);
// Hi, I'm Rahul from Mumbai, India   
```

|           | `call()`                                  | `apply()`                              |
| --------- | ----------------------------------------- | -------------------------------------- |
| Arguments | Passed **individually** (comma-separated) | Passed as an **array**                 |
| Syntax    | `fn.call(thisArg, arg1, arg2, ...)`       | `fn.apply(thisArg, [arg1, arg2, ...])` |
## When to Use Which?

- **`call()`** → You know the exact arguments upfront.
- **`apply()`** → Arguments are already stored in an **array** (or array-like object), or the number of arguments is dynamic/unknown at runtime.

## The bind Method

```Typescript title="demo.ts"
const john = {
    name: 'John',
    age: 30,
    whoAmI : function(greet:string){
        console.log(`${greet} , I am ${this.name}, aged ${this.age}`);
    }
};

// john.whoAmI('Heelo'); // Heelo , I am John, aged 30

const Intro = john.whoAmI;

//Intro('Hi'); // Error cannot read 'this'
// Fix using bind method
const jo = Intro.bind(john); // now 'this' is bind to 'john' object
jo('heeeeeeloooo');

const jo2 = Intro.bind(john,'hi'); // now 'this' and 'hi , both are bind to jo2.
jo2();  // hi , I am John, aged 30
```

What we did here is specifying parts of the argument beforehand. This is common pattern called 'Partial application'
